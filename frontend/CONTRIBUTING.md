# Contributing to Grantify

Thank you for your interest in contributing to Grantify! We are building a platform that makes a real difference for students and innovators in Nigeria, and we welcome your help.

## 🌈 How to Contribute

### 1. Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug and provide steps to reproduce it.
- Mention your environment (browser, OS).

### 2. Suggesting Enhancements
- Open an issue with the "enhancement" label.
- Explain why this feature would be useful for the Grantify community.

### 3. Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm test` if applicable).
5. Make sure your code lints (`npm run lint`).

## 🎨 Design Guidelines
- Follow the "Premium Dark" aesthetic.
- Use `framer-motion` for all UI transitions.
- Maintain DRY principles by reusing components from `src/components`.

## 📜 Code of Conduct
Please be respectful and professional in all interactions. We aim to foster a collaborative and inclusive environment for all Nigerian developers.
